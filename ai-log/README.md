# AI interaction log

This directory is the record of how this challenge was actually built with AI agents:
what I asked, what the model produced, and where I accepted, rejected, or redirected it.

It is deliberately not tidied up. Where the model was wrong, the wrong answer is still in
the transcript, followed by the correction.

## Tools and models used

> One honest line, updated as I go — see `decisions/` entries for the per-step detail.

- **Claude Code (Claude Opus 5, 1M context)** — primary agent. Used for: reading and
  translating the brief, pressure-testing my interpretation of the ticket, authoring the
  implementation plan with me, generating backend/frontend code, and writing this log
  tooling. I reviewed every diff before committing.

## Structure

| Path | What it is |
|---|---|
| `raw/*.jsonl` | Unedited Claude Code session transcripts, straight off disk. Source of truth. |
| `raw/*.md` | Human-readable render of the same sessions, generated by `export-ai-log.ps1`. |
| `decisions/` | Short, in-the-moment entries: what I asked for, what came back, what I did about it and why. |
| `reflection.md` | Written at the end: the specific moments I caught the agent being wrong or overrode it. |
| `export-ai-log.ps1` | The exporter itself. Not required by the brief — I wrote it so the raw log is reproducible rather than hand-copied. |

`raw/` is machine-produced and complete. `decisions/` is where my judgment lives — the
transcript shows *what happened*, the decision entries show *why I let it happen or stopped it*.

## Regenerating the raw log

```powershell
./ai-log/export-ai-log.ps1
```

Reads `~/.claude/projects/<project>/*.jsonl`, copies each session verbatim into `raw/`,
and renders a Markdown version beside it. Nothing is edited or dropped; tool results longer
than ~2000 chars are truncated in the Markdown render only, and the truncation is marked
inline. The `.jsonl` next to it is always complete.

## Notes on honesty and language

- The working conversations are in **Spanish** (my first language) and are committed as-is.
  This file and the `decisions/` entries are in **English** so the reviewer can follow the
  reasoning without translating anything.
- The transcripts include false starts, a truncated model reply I interrupted, and at least
  one judgment call the model made on its own that I had to confirm or override. Those are
  left in on purpose.
